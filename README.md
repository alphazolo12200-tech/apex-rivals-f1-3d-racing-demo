# Apex Rivals – F1 3D Racing (Free Demo)

A single-file 3D Formula-style racing game that runs in your browser. No install, no sign-up.

**This is the free demo: 2 of the 8 missions are playable.** The full game adds 6 more missions on 3 more circuits.

## What is in the demo

- Mission 1: **Training Lap** (Rookie Ring, solo, beat the par time)
- Mission 2: **Rookie Cup** (Rookie Ring, 3 laps, 3 AI rivals, finish on the podium)
- XP, levels, win streaks, tyre compounds, pit lane, weather, replay and split-screen for 2 players

## How to play

1. Download this repository (green **Code** button, then **Download ZIP**) or the demo zip from Releases, and unzip it.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. Pick a mission and race.

The game loads the three.js library from the internet (cdnjs), so connect to the internet the first time you open it.

## Controls

| Action | Player 1 | Player 2 (split screen) |
|---|---|---|
| Steer / throttle | W A S D or arrow keys (single player) | Arrow keys |
| Brake | Space | Down arrow |
| Reverse | Q | / |
| Driving aids | G | L |
| Choose tyres in the pit | 1 2 3 4 | 7 8 9 0 |
| Back to menu | Esc | |

On phones and tablets, use the on-screen buttons.
